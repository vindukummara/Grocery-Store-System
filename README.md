# 🛒 Grocery Store Management System

## 📌 Project Overview

The Grocery Store Management System is a Streamlit-based web application developed using Python. It helps manage grocery store operations such as product management, billing, customer management, supplier management, sales reports, and stock monitoring.

---

## 🚀 Features

- 🔐 Login & Logout
- 🏪 Dashboard
- ➕ Add Product
- 📋 View Products
- ✏️ Update Product
- 🗑️ Delete Product
- 🔍 Search Product
- 🛒 Billing System
- 📄 PDF Receipt Generation
- 📉 Low Stock Alert
- 📊 Sales Report
- 👥 Customer Management
- 🚚 Supplier Management
- 🖼️ Product Image Upload

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- ReportLab
- CSV Files

## ⚙️ Installation

Clone or download the project.

Install the required packages:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
streamlit run app.py
```

The application will open in your web browser.
